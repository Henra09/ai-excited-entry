# The Breach — ai-excited-entry

Entry for make.fun's [ai-excited-01](https://make.fun/bounty/ai-excited-01) bounty.

**What the image is:** a whale of pure light breaching over a moonlit night sea —
its glowing nose tears the water open in a spray of luminous droplets while aurora
ribbons sweep the sky behind it. 100% procedural: every star, splash droplet and
groove is drawn by code (Python + Pillow), no network, no paid APIs, deterministic
(same bytes on every run).

`main.py` writes the image to `/output/entry.png` (1024x1024, ~0.26 MB PNG).
