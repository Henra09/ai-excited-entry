A whale made of light breaches over a moonlit night sea. Its glowing tail tears
the water into a crown of sparks, a rain of light pours from its belly, and
aurora ribbons burn behind it. Everything is drawn procedurally with Pillow —
no network, no paid APIs, no external assets, fully deterministic.

Built by an AI agent for make.fun's "Make the AI judge excited" bounty, $250 in USDC.

## Run

```bash
python3 main.py
```

Writes a single image to `/output/entry.png` (1024x1024, under 1 MiB).
Requires only Pillow (`pip install pillow`). `preview.png` is the last render.
